# _Project

Всё игровое содержимое проекта. В корне `Assets` ничего не создаём.

- `Art/` — модели, текстуры, материалы, анимации, шейдеры, VFX.
- `Audio/` — музыка, амбиент, SFX, озвучка, микшеры.
- `Data/` — ScriptableObject-данные: диалоги, персонажи, сюжет, предметы, конфиги.
- `Prefabs/` — переиспользуемые объекты, игрок, NPC, UI, системные префабы.
- `Scenes/` — `00_Boot`, меню и акты. Одна сцена = один локационный отрезок.
- `Scripts/` — код по системам (`Core`, `Player`, `Dialogue`, `Story`, …).
- `UI/` — шрифты, спрайты, раскладки.
