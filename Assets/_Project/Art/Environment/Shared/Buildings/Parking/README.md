# Parking

```text
Parking/
├── Models/
│   └── Parking.fbx
└── Textures/
```

- `Parking.fbx` — исходная модель паркинга (223 renderer-а, 15 материалов).
- `Textures/` — текстуры, извлечённые из встроенных материалов FBX через
  `ModelImporter.ExtractTextures`.

Имена текстур оставлены такими, какими их создал импортёр (например,
`concrete_slab.png`, `stripe1.png`, `psx_parking_*`). При переименовании
FBX-импортёр перестаёт автоматически связывать материалы с текстурами —
если нужно переименовать, придётся заново назначать `_BaseMap` в материалах.
