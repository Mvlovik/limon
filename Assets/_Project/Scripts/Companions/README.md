# Companions — напарник и маршрут по триггерам

Универсальная система для NPC, который по команде расставленных в сцене
триггеров идёт к точкам маршрута. Преследование игрока — опциональный
режим. Работает в любой сцене: не требует NavMesh, Rigidbody или
CharacterController.

## Состав

| Компонент | На что вешать | Что делает |
|---|---|---|
| `CompanionActor` | на корень NPC (например, `Joe`) | Идёт к точкам по триггерам. Новый триггер сразу перехватывает цель. |
| `CompanionWaypoint` | на пустой объект — точку маршрута | Позиция, радиус прибытия и пауза в точке. |
| `CompanionWaypointTrigger` | на объект с `Collider` (Is Trigger) | Когда игрок входит в зону, отправляет напарника к привязанной точке. Ловит быстрый проскок. |
| `Animator` + `Joe_Walk.anim` / `Joe_Idle.anim` | на корень NPC | Анимация шага и idle. Клипы лежат в `Art/Animations/Joe`. |

## Как собрать в новой сцене

1. На корень NPC добавьте `CompanionActor`.
   - `Follow Player` по умолчанию выключен: NPC стоит на месте и идёт
     только к точкам по триггерам. Включите, если нужен режим сопровождения.
   - `Player Tag` — тег игрока (`Player` по умолчанию).
   - `Player Override` — если игрок не тегирован.
2. Создайте пустые объекты — точки маршрута, добавьте на них
   `CompanionWaypoint`. Держите их на уровне пола (Y — ноги NPC).
3. Создайте объекты-зоны с `BoxCollider` (галочка **Is Trigger**),
   добавьте `CompanionWaypointTrigger`.
   - `Actor` — напарник (если пусто, найдётся первый в сцене).
   - `Waypoint` — точка, к которой он пойдёт.
   - `Detect Fast Movement` включён по умолчанию: триггер проверяет
     отрезок между прошлой и текущей позицией игрока и не пропускает
     зоны, пройденные на бегу.
   - `Order` — порядковый номер для порядка в инспекторе и отладки.
     На переключение цели он не влияет.
4. События `On Activated` на триггере можно использовать для мыслей,
   звука или диалога; для прибытия подпишитесь на
   `CompanionActor.WaypointReached` из кода.
5. Для анимации добавьте `Animator` с контроллером `Joe.controller`.
   Клипы пересобираются меню
   **Tools → GameLimon → Rebuild Joe Animation (Clips + Animator)**.
   Имена объектов для клипов: `Body`, `Head`, `LeftLeg`, `RightLeg`,
   `LeftArm`, `RightArm`, `Elbow`, `Knee`.

## Правила движения

- NPC стоит на месте, пока игрок не активирует триггер.
- При активации триггера он идёт к точке. После прибытия стоит
  `Hold Seconds` секунд и остаётся там.
- **Любой новый триггер сразу перехватывает цель**, даже если NPC ещё
  бежит к предыдущей точке. Joe разворачивается и идёт к последней
  активированной точке.
- Каждая точка активируется один раз. Повторная активация прошлого
  триггера игнорируется — вернуться к прошлой точке нельзя.
- Если игрок за один кадр или за пару кадров проскакивает несколько зон,
  срабатывают все; напарник идёт к последней активированной.
- Опциональное `Follow Player` включает режим сопровождения: без активной
  точки NPC догоняет игрока и останавливается на `Follow Stop Distance`.

## Анимация

- `Joe_Walk.anim` — цикл шага: бедро, колено, руки, локти, наклон и
  покачивание корпуса, стабилизация головы.
- `Joe_Idle.anim` — idle: дыхание, перенос веса, покачивание рук и
  повороты головы.
- `Joe.controller` — параметры `Speed` (переход Idle ↔ Walk) и
  `PlaybackSpeed` (частота шага под скорость движения).
- Скорость шага задаёт `CompanionActor`: `Speed` — нормализованная
  скорость, `PlaybackSpeed` — множитель проигрывания клипа.
